# pair-wise-yy-60 碳减排项目监测证据核验与签发准备平台

按监测周期完成活动数据、排放因子、证据来源、异常波动和计算链核验。支持抽样任务、版本化数据修订、发现项闭环、签发前完整性检查，以及方法学期中换版的可追溯处置。

## 方法学期中换版规则

换版日 `2026-07-16`（CMS-052-V01 → V02），页面 `/methodology` 与接口 `/api/methodology` 落地以下规则：

1. **旧数据不整批套新因子**：按发生日期保留原排放因子与计算依据——换版日之前的记录（如 ACT-0318，07-14）确认后仍锁定 V01 因子。
2. **新到现场数据走新版**：换版日（含）之后的记录按 V02 新因子计算，差异逐条列出。
3. **确认带当前批次版本**：整批确认携带批次版本号做乐观锁；两位核验员同时提交时先到者成立（版本进位），后到者收到冲突响应并看到最新版本与未处理差异。
4. **写入失败从未确认记录恢复**：失败只保留无版本号的未确认记录；恢复使用确定性 clientToken 幂等重试，不重复生成版本。
5. **旧数据回填首版**：缺方法学版本的历史记录升级时回填 V01 首版因子，并列出待复核原因。
6. **签发只接收完整批次**：现场数据齐备且换版确认成立后批次才完整；不完整批次在签发准备页被门禁拦截。

## 技术栈

Next.js App Router、MUI、Zustand、TanStack Query、ky、Zod、TypeScript。

## 运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62060`。

- `/api/evidence`：监测证据记录（含发生日期、方法学版本、因子计算依据）。
- `/api/methodology`：换版批次状态机，支持 `write / recover / confirm / backfill / importFieldData / reset` 动作。

```bash
npm run build
```
